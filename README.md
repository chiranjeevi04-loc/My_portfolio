# Goligi Chiranjeevi: E-Portfolio

## Run locally in VS Code
1. Open the `portfolio` folder in VS Code (File > Open Folder).
2. Install the **Live Server** extension (Ritwick Dey).
3. Right-click `index.html` and choose **Open with Live Server**. (Or just double-click `index.html`.)
An internet connection is needed for Google Fonts and Font Awesome icons.

## Edit your content
- Skills, projects, certifications, interests, languages: top of `script.js`.
- Add a project GitHub link: set `repo: 'https://github.com/...'` in that project. The GitHub button appears only when a link is set.
- Internship organisation name: `id="internOrg"` in `index.html`.
- Profile photo: save it as `assets/profile.jpg`, then follow the comment in the hero section of `index.html`.
- CV: replace `assets/Chiranjeevi_CV.pdf`.
